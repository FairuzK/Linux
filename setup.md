## Core Linux Tasks
These are tasks you can get comfortable with the Linux Fundamentals

- Use Killercode (By the team)
- Install Unbuntu natively (Ubuntu 22.04/24.04 recommended)
- Use WSl2 (Windows Subsystem for Linux)
- Can use AWS EC2 (t2 micro free tier)
- Use a VirtualBox / VMware VM

### Commands Verifying Setup
```bash
uname -a
whoami
pwd 
```
